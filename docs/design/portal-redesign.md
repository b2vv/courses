## Branch і що вже вирішено
- Це **система + сторінки**, не один екран. Фундамент уже сильний і адаптивний: токени (light/dark, forced-colors, reduced-motion), UI-набір, ≥44px, фокус, 7 медіа-квері + плинні сітки в `main.css`, e2e «мобільний+200%» зелений. Тому це **редизайн-вирівнювання під мокап**, не переписування з нуля.
- Палітра майже збігається: мокап `--primary #5d4df4` ≈ наш `#5735e9`; лайм-акцент і code-мотив спільні.

## Дельта до мокапу (що змінюємо) — вільні осі
1. **Радіуси більші/пігулки.** Мокап `--radius .75rem` скрізь; бейджі й фільтри — пігулки (badge «Нова програма·Agentic AI», фільтри Усі/Frontend/Backend/AI, теги рівня). Наш `--radius-control .375rem` → підняти для карток/кнопок; додати pill-варіанти.
2. **Hero — багатошаровий, з глибиною.** Плаваюча картка «найпопулярніший курс» + окрема плаваюча картка прогресу зі світінням/тінню й subtle-grid фоном; пігулка-бейдж; вторинний CTA «Трейлер» з play-іконкою; рядок статистики (4800+ студентів, 4.9/5). Наш hero — площинний бокс.
3. **Картки курсу — багатші й ПЛАТІЖНО-обізнані (лягає на O05).** Хедер-градієнт з іконкою (top-left) + пігулка рівня (top-right) + декоративне коло; категорія (FRONTEND/…); назва; біле тіло: мета (уроки, год), рейтинг (зірки, к-ть), **ціна + «У кошик»**. Наш card: лише градієнт+</>+назва+опис.
4. **Рядок ціннісних пропозицій** (Практика / Code review / Доступ назавжди) з круглими іконка-тайлами.
5. **Багатший футер** (лого-знак grad-cap + таглайн + колонки Навчання/Підтримка).
6. **Лого-знак** grad-cap у крузі (зараз `</>` у квадраті) — опційно.

## Адаптивність (вимога)
Кожен екран верифікувати на 3 ширинах (≈390 / 768 / 1280) через **Playwright-скріншоти** (розширення знімає фіксовано — ненадійне для мобільного). Сітки карток auto-fit/minmax; hero стекається; nav → мобільне меню; таблиці адмінки — горизонтальний скрол/картки.

## Скоуп і слайси (пропозиція)
- **D-a Токени/примітиви:** радіуси, pill-badge, icon-tile, floating-card+shadow/glow, stat-row — у tokens.css/ui. База для решти.
- **D-b Storefront:** hero (шари+статистика+2 CTA), картки курсу (мета/рейтинг/ціна/кошик — ціна вже є з O04 каталогу), фільтр-пігулки, ціннісний рядок, футер. Верифікація 3 ширини.
- **D-c Learn (сторінка уроку):** щільний екран плеєр+транскрипт+обговорення — ритм, ієрархія, адаптив на вузькому.
- **D-c Admin:** таблиці/форми авторингу — вирівняти під систему, адаптив (скрол/картки на мобільному).
- Не ламати наявні e2e (a11y/структура). Ціна/кошик у картці — синхронізувати з O05 (платіжний UI), тож **D-b і O05 роблю разом або D-b перед O05**.

## Ризик №1
Візуальна фіделіті VS не зламати a11y/e2e й не протягнути shadcn-залежності. Мітигація: лише токени+React Aria; кожен слайс — Playwright-скрін (3 ширини) + `npm run lint/typecheck/rstest` + повний e2e перед мержем.

## Референс адмінки (відео користувача, 2026-09-30, 57с)

Окремий таргет для **D-d admin** — вишуканий темний **ops-дашборд** (кадри збережено
`docs/design/reference/admin-ref-*.jpg`). Мова стилю й анімацій:
- Ліва icon-навігація з секціями (Overview/Activity/…, RECENT, INFRASTRUCTURE, PROJECTS), rounded
  workspace-switcher угорі; активний пункт — підсвічена пігулка.
- Багаті картки: прогрес-кроки з лініями, таблиці метрик із **delta-пігулками** (зелена/червона),
  донат/бар-чарти, sparkline-и, горизонтальні load-метри, timeline «lifecycle».
- Моноширинні ідентифікатори (`payments-api v4.22.1`), статус-пігулки (Healthy/Rolling out/Succeeded),
  сегментні контроли (1h/24h/7d/30d), великі метрики з delta.
- Анімації: заповнення прогрес-кроків/барів, лічильники, плавні переходи вью.

**Принцип (важливо):** беру **мову стилю й анімацій**, накладаю на **реальний контент нашої адмінки**
(курси, акаунти, авторинг, модерація коментарів, гранти) — НЕ копіюю ops-віджети (deployments/incidents
доменно чужі). Напр.: «Overview» адмінки = метрики курсів/студентів/модерації з delta-пігулками й
чартами; таблиці курсів/акаунтів у стилі service-health; авторинг-форми в картках дашборда.
Стек той самий — React Aria + токени, без shadcn/Tailwind/Recharts-важких залежностей (чарти — легкий
inline SVG/CSS, не нова важка бібліотека без потреби).

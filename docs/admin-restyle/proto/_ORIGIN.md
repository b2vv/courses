# Походження цього прототипу

Це **референс цільового вигляду** admin-restyle від плагіна (React + React Aria + plain CSS),
скопійований сюди 2026-10-14 з ефемерного session-scratchpad, щоб пережити зміну сесій.
Він **не збирається і не йде в прод** — перекладається на наш код і токени (див.
`../plan.md`, `../tickets.md`). Пропущено навмисно: `dist/app.js` (збірка, 796 КБ),
`dist/fonts/*.woff2` (media-байти — не комітимо), `package-lock.json`, build-плумбінг.

Файли: `README.md` (нотатки дизайну прототипу), `src.jsx` (DOM/aria/класи), `styles.css`
(токени/ваги/класи, = `dist/styles.css`), `fixtures.js` (форма демо-даних), `interactions.mjs`.

## ⚠️ Де еталон РОЗХОДИТЬСЯ з рішенням власника

`README.md` §Contrast каже тримати primary-ТЕКСТ великим (1.1875rem/750, large-bold 3:1) і
«must not be reduced». **Рішення 1 власника (2026-10-14, підтверджено двічі) це перекриває:**
у прод primary = **поглибити ЗАЛИВКУ** до `color-mix(in srgb, var(--color-primary) 86%, #000)`
= `#4763d0` (5.30:1 normal-text AA), **тримаючи нашу button-шкалу `.8125rem/650`** — текст НЕ
роздуваємо. Еталон вигляду лишаємо, трактування контрасту — наше. Градієнт на кнопці (білий на
`--btn-primary-bg`) верифікувати вручну (axe пропускає градієнти).

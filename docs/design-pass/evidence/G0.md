## Lenses

**anti-slop §3 pre-flight.**
- Nothing new is decorative: the hamburger glyph sits beside the word «Меню» and the close button's × has an accessible name.
- The card shadow separates the card from the dimmed page.
- The palette and fonts are the existing tokens.
- No fabricated content.
- No motion.

**ux-review (diff).** Defects found during this pass and fixed:
1. Following the menu's link to the current page left the menu open, because the address did not change. Fixed by closing the menu on any press of a menu link.
2. The retry button sat directly against the explanation above it. Fixed with a 12 px gap.

No blocker or major finding remains open.

**Pre-existing, outside the diff:**
- The catalog failure page has no `h1` (only the error `h2`).
- The `rstest` warning «Generated path "/learn" matched "/learn/$"».

## Codex review

**Round 1** (`cc36e0a9`): **BLOCK**, four P2 findings, all fixed in the next commit.
1. The admin header at 1024 wrapped to 109 px. The breakpoint moved to 68em; 1024 is now compact for every role, and from 1100 every role fits one row.
2. `accessibility.spec.ts:250` (admin controls at 1280 with 200% text) looked for controls that are now inside the menu. The test now opens «Меню» and measures the targets and overlaps inside the card.
3. Back and then Forward reopened the menu. The menu now closes on the router's `onBeforeNavigate`.
4. The footer had no «Акаунт» or «Увійти», although §13 promised them. The plan was corrected with a dated author decision: both stay in the header only, because duplicate link names break strict locators.

## Decisions for the owner (stylistic, not gating)

- **Guest at 768 and on a phone.** «Увійти» is now inside the menu. Before, it was visible but cost a second header row. The alternative is to keep «Увійти» beside «Меню» in the compact row where it fits.

## Also in this branch

`.dockerignore` now excludes `frontend/test-logs`, `frontend/playwright` and `frontend/storybook-static`.
- Every e2e run writes a new api+nginx log into `frontend/test-logs` (`Makefile:88`): 208 files, 367 MB.
- Git ignores them; Docker did not. So each frontend build sent a context of about 450 MB, and a COPY layer of 0.45–0.55 GB was added to the `kiri-build` cache on every gate run.
- After the change the build context is **17 MB** (`transferring context`).
- The cache was 16 GB before the owner-approved prune of 2026-11-22.

**Round 2** (`5e4d5353`): **PASS**, no findings. Instructor identity was NOT_TESTED by Codex; the author measured it, with the same result as the admin.

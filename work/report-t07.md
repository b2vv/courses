## Decisions

- `/admin` remains the authenticated admin/instructor layout. The users child adds the narrower
  account-administration capability check before its loader, so an instructor gets the same
  not-found screen as an unknown route and no directory request is made.
- `validateSearch` echoes only `status`, `q`, and `page` exactly as received. A second step parses
  fields independently, defaults unusable values to all statuses/empty query/page 1, and never
  rewrites the original address. Filter or search changes reset paging; page changes retain valid
  filters.
- Active rows expose block, blocked rows expose restore, and both expose delete and password reset.
  Deleted rows are visible only when returned by the deleted filter and expose no server-refused
  mutation. Server enforcement remains authoritative for self-target, immutable-admin, and
  last-admin refusals.
- Every successful mutation uses T06's shared list invalidation. Named mutation failures render in
  an alert; `authentication_required` clears the session cache. A successful reset of the caller
  announces the sign-out and then clears that same cache so the guarded layout redirects.
- No dependency, backend surface, course-screen behavior, e2e file, or file inside a `generated/`
  directory was added or changed.

## Наступний хід

**Editor-polish (lesson-builder WYSIWYG) — готовий до роботи, аналіз зроблено 2026-10-13.** Жива проходка редактора + reader (admin на `localhost:8080`) показала: функціонально повний типізовано-секційний редактор, але **візуально голий MVP** (CSS-класи без оформлення — секції зливаються, сирий file-input, слабка прозова типографіка reader). Codex-аналіз (`docs/lesson-builder/_wip-editor-design-codex.md`) дає ранжований план: **QW1** видимі межі/зона вводу секції → **QW2** переюз `FileUpload`/`TextField` для зображення → **QW3** прозова типографіка reader+editor + виразний task → **QW4** grid колонок + підписи палітр → **QW5** toolbar-групування + active-state → **QW6** loading/error/empty; далі поведінковий слайс **D1** чесні save/publish/upload-статуси, **D2** URL-помилка/фокус. Усе на наявних токенах/примітивах + scoped CSS (Tailwind у репо є, але house-style — токени+React Aria), без нових залежностей. Розмір: `spec-flow` (крос-зріз FE) або серія `to-tickets`. **Це рекомендований наступний хід, якщо власник хоче рухати WYSIWYG.**

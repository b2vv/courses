## Decisions

- `/admin` remains the sole guarded shell. `requireIdentity`, the admin/instructor role check,
  `ssr: false`, pending/error handling for identity, and `useRedirectWhenSessionEnds` remain on
  the parent; the index child owns only list concerns.
- `validateSearch` echoes only known fields exactly as received and applies no defaults. A second
  step parses `status` and `page` independently, drops an unusable field, and defaults once to all
  statuses/page 1. The list uses a fixed 20-row page, bounded to the API's maximum offset.
- Status changes reset pagination to page 1. Page changes keep a usable status filter. Neither
  interaction carries unusable or unknown URL data forward.
- The list shows the `instructorId` already present in each admin row. It does not mount the
  instructor query or provide an owner picker; that stays with A11 under D-4c.
- The list error boundary uses the kit's `ErrorState` without 503-specific retry behavior. A12
  still owns R37/R38/R40.

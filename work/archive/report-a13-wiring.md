# A13 wiring — звіт

Дата: 2026-09-24

## Зроблено

- C17 проведено від `LessonDraftField` через `CourseEditorView` до редактора того самого уроку.
  Стан пропозицій ізольований за `lesson.id`, тому завантаження однієї чернетки не змінює інші
  уроки.
- Додано єдиний тип `TranscriptDraftOffer` із `segments`, `language` і `updatedAt`.
- Завантаження чернетки тепер змінює активну мову редактора на мову чернетки; збереження йде з
  цією мовою, тому текст не зберігається під мовою транскрипту мовчки.
- C18: `TranscriptSnapshot` і `TranscriptBaseline` несуть токен ASR-чернетки. `recoveryOffer`
  повертає `offer-stale`, якщо токен завантаженої чернетки змінився. Ручні знімки без токена
  зберігають попередню поведінку.
- Поточний токен готової чернетки також передається з `LessonDraftField` у редактор незалежно від
  того, чи натиснув автор «завантажити»; тому після reload і перегенерації recovery має токен для
  порівняння.
- Пропозиція ASR показується лише коли recovery не має власної пропозиції; прийняття замінює
  рядки без перемонтування, відхилення та прийняття викликають `onDraftOfferHandled`.
- Додані unit-тести для порівняння токенів, пропозиції редактора і маршрутизації пропозиції між
  двома уроками.

## Рев'ю чужого WIP

Правильно було використано наявний шлях recovery як єдиний UI-механізм, а `loadedDrafts` жив у
спільному батьківському стані `LessonFields`, що дозволяло зв'язати два sibling-компоненти без
глобального стану. Також правильно було не перемонтовувати `TranscriptEditor` при завантаженні.

Виправлено:

- `LessonDraftField` передавав мову, але WIP її викидав; тепер вона є частиною єдиного типу
  пропозиції й визначає мову збереження.
- WIP не передавав `draft.updatedAt`, тому C18 не міг відрізнити перегенеровану чернетку;
  токен додано в пропозицію, snapshot і baseline.
- JSX IIFE-спред замінено локальною змінною `draftOffer` у циклі уроків.
- Додано відсутні перевірки C18 і wiring для кількох уроків.

## Перевірки

- `npm run typecheck` — пройшов.
- `npm run lint` — пройшов; architecture check: 114 файлів.
- `npm run format:check` — не пройшов через форматування незміненого `frontend/e2e/media.setup.ts`.
  Змінені `src/`-файли прогнані через `oxfmt` окремо.
- `npm test` — не виконав тести: Rstest завершився до запуску тестів із `listen EPERM ::1:3000`.
  Targeted Rstest запуск має ту саму відмову.
- Docker та e2e не запускалися за брифом.

## Discussion

Поточне середовище забороняє Rstest слухати `::1:3000`, тому немає runtime-доказу для доданих
тестів у цій сесії. Це обмеження запуску тестового раннера, а не assertion failure; потрібен запуск
у середовищі reviewing session, де дозволений локальний listener.

## Правка після рев'ю

Reviewing-сесія виконала `npm test`: 471/472 тестів були зелені. Єдиний failure був у новому
тесті `CourseEditorView.test.tsx`: тест очікував рядки `Loaded` одразу після кліку `Load draft
into editor`. Це пропускає передбачений C17 проміжний крок: перший клік лише показує пропозицію
в `TranscriptEditor`, а рядки замінюються після `Load the draft`.

Тест виправлено без змін wiring: після першого кліку він перевіряє, що пропозиція є лише в
редакторі першого уроку, натискає `Load the draft`, а потім перевіряє `Loaded`, незмінений
`Second old` і відсутність `First old`. Змінені файли відформатовано `oxfmt`.
Після повторного прогону локатор заголовка уточнено до фактичного accessible name `Lesson transcript`.
